# Voice-overs (optional)

Put ElevenLabs mp3s here with these exact names and the site plays them on cue:

| File | When it plays | Suggested line |
|---|---|---|
| `vo-intro.mp3` | curtains open | "Ladies and gentlemen... live from Cherokee, North Carolina... it's... THE PAYTYN SHOW!" |
| `vo-zbb.mp3` | Zac Brown Band act | "Alright y'all, boots on... it's Zac Brown Band night!" |
| `vo-credits.mp3` | the very end | "Happy twentieth birthday, Paytyn! ...And yes. This is where all my A.I. credits go to." |

Missing files are skipped. If `vo-credits.mp3` is missing, the phone's built-in voice reads the last line instead.
